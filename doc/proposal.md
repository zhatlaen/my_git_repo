 ## 1. 项目概述

  ### 1.1 项目目标

  开发一款基于 Python + pygame 的经典贪吃蛇游戏，采用简约像素风视觉设计，具备完整的游戏流程（开始→游戏→暂停→结算），支持
  后续打包为 Windows 可执行文件。

  ### 1.2 核心特色

  - 🎮 经典玩法 + 流畅操作体验
  - 🎨 简约像素风 + 清晰视觉反馈
  - 📊 实时分数 + 历史最高分记录
  - ⚙️ 模块化架构，便于扩展与维护

  ———

  ## 4. 视觉设计规范

  ### 4.1 像素风格参数

  窗口尺寸：800×600
  游戏区域：600×600（20×20 像素格子，每格 30×30px）
  UI 边栏：200×600（分数/进度/操作提示）
  蛇身颜色：#4CAF50（绿色像素块）
  食物颜色：#F44336（红色像素块）
  背景色：#1a1a2e（深空蓝）
  字体：像素字体（8px/12px/16px 三档）

  ### 4.2 动效反馈

  - 蛇吃到食物：轻微缩放动画 + 粒子闪烁
  - 游戏结束：屏幕震动 + 红色边框闪烁
  - 按钮悬停：像素边框高亮
