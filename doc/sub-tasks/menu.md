# 模块任务：menu（菜单界面）

> 文件：src/ui/menu.py  
> 职责：开始/暂停/结算界面的渲染与交互

## ? 最小可执行任务清单

- [ ] **菜单类型枚举**：定义 MenuType：START/PAUSE/GAME_OVER
- [ ] **动作枚举**：定义 MenuAction：START_GAME/RESUME/RESTART/QUIT/NONE
- [ ] **初始化**：实现 __init__，接收字体/资源/配置，预加载菜单元素
- [ ] **菜单渲染**：实现 draw(surface, menu_type)，按类型绘制对应菜单界面（标题/选项/装饰）
- [ ] **输入处理**：实现 handle_input(events)，方向键选择选项，回车确认，返回 MenuAction
- [ ] **选项高亮**：实现当前选中项的像素边框高亮效果
- [ ] **遮罩绘制**：暂停菜单支持半透明遮罩层，不影响底层游戏画面
- [ ] **结算数据**：GAME_OVER 菜单支持传入本局分数和是否破纪录进行展示
- [ ] **交互测试**：验证菜单选择/确认/返回流程符合预期

## ?? 验收标准

- [ ] 三种菜单类型渲染正确，像素风格一致
- [ ] 方向键可循环选择选项，回车触发对应动作
- [ ] 暂停遮罩半透明，底层游戏画面可见
- [ ] 结算界面正确显示分数和破纪录提示
- [ ] 菜单逻辑不依赖游戏状态，可独立测试
