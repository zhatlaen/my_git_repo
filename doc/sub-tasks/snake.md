# 模块任务：snake（蛇实体逻辑）

> 文件：src/game/snake.py  
> 职责：管理蛇的移动、生长、碰撞检测

## ? 最小可执行任务清单

- [ ] **初始化蛇身**：实现 __init__，接收起始位置/格子尺寸/初始长度，初始化 ody 列表和 direction
- [ ] **方向设置**：实现 set_direction(new_dir)，禁止180°反向，返回设置是否成功
- [ ] **移动逻辑**：实现 move()，按方向更新蛇身坐标，返回移动是否成功
- [ ] **生长逻辑**：实现 grow()，尾部增加一节，不移除尾节点
- [ ] **碰撞检测-越界**：实现 check_collision(bounds) 中的越界判断，返回 'wall' 或 'none'
- [ ] **碰撞检测-自撞**：实现 check_collision(bounds) 中的自撞判断，返回 'self' 或 'none'
- [ ] **获取蛇身坐标**：实现 get_segments()，返回从头到尾的像素坐标列表
- [ ] **获取蛇头位置**：实现 get_head_pos()，返回蛇头像素坐标
- [ ] **单元测试**：编写纯逻辑测试（无需pygame），验证移动/生长/碰撞函数

## ?? 验收标准

- [ ] 蛇能按方向键流畅移动，无卡顿
- [ ] 反向按键被正确拦截（如向右时按左无效）
- [ ] 撞墙/撞自身能准确返回对应碰撞类型
- [ ] 生长后蛇身长度+1，坐标链连续
- [ ] 所有函数含 docstring，类型注解完整
