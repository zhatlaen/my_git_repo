# 模块任务：assets（资源管理）

> 文件：src/ui/assets.py  
> 职责：像素精灵资源缓存与管理

## ? 最小可执行任务清单

- [ ] **初始化**：实现 __init__(asset_dir)，验证资源目录存在，初始化缓存字典
- [ ] **精灵加载**：实现 load_sprite(name)，加载PNG并缓存，返回 pygame.Surface
- [ ] **动画帧加载**：实现 get_animation(name)，加载序列帧（如 ood_eat_0.png~_3.png）
- [ ] **缓存机制**：相同资源键名只加载一次，后续直接返回缓存对象
- [ ] **降级方案**：资源加载失败时返回纯色占位方块，避免崩溃
- [ ] **资源键名规范**：定义标准键名：snake_head/snake_body/ood_apple/g_grid 等
- [ ] **内存管理**：提供 unload(name) 或 clear() 方法，支持资源释放
- [ ] **加载测试**：验证资源缓存命中率和降级方案有效性

## ?? 验收标准

- [ ] 首次加载资源后，二次请求直接返回缓存，无重复IO
- [ ] 动画帧按顺序加载，返回列表长度正确
- [ ] 缺失资源返回占位方块，程序不崩溃
- [ ] 资源键名统一，便于其他模块调用
- [ ] 支持后续扩展新资源类型（如音效/配置文件）
