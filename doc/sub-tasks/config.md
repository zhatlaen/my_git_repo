# 模块任务：config（配置常量）

> 文件：src/utils/config.py  
> 职责：配置加载 + 全局常量定义

## ? 最小可执行任务清单

- [ ] **常量定义**：定义核心常量：GRID_SIZE=20/BOARD_COLS=30/BOARD_ROWS=30/INITIAL_FPS=8 等
- [ ] **颜色配置**：定义 COLORS 字典：蛇身绿#4CAF50/食物红#F44336/背景深蓝#1a1a2e 等
- [ ] **速度参数**：定义 SPEED_INCREMENT=1.1/MAX_SPEED_RATIO=1.5 等游戏平衡参数
- [ ] **配置加载函数**：实现 load_config(config_path)，读取JSON配置文件，返回字典
- [ ] **默认配置**：配置文件不存在时返回内置默认值，不报错
- [ ] **配置验证**：关键参数（如窗口尺寸）加载后做范围校验，非法值使用默认
- [ ] **热重载支持**：预留 eload_config() 接口，支持开发时动态调整参数
- [ ] **配置测试**：验证默认配置/文件配置/异常配置三种场景加载正确

## ?? 验收标准

- [ ] 所有常量集中管理，其他模块通过导入引用，无硬编码
- [ ] 配置文件格式标准JSON，键名清晰，支持注释说明
- [ ] 配置加载失败时有日志提示，程序使用安全默认值继续运行
- [ ] 新增配置项只需修改本文件，不影响其他模块
- [ ] 配置值类型安全，数值参数有合理范围限制
