# 模块任务：storage（本地数据持久化）

> 文件：src/utils/storage.py  
> 职责：最高分等本地数据的读写持久化

## ? 最小可执行任务清单

- [ ] **加载最高分**：实现 load_highscore(storage_path)，读取JSON文件，不存在时返回0
- [ ] **保存最高分**：实现 save_highscore(score, storage_path)，写入新纪录，返回是否成功
- [ ] **目录创建**：保存前自动创建 data/ 目录（如不存在），避免路径错误
- [ ] **异常处理**：文件权限/磁盘满等异常时记录日志，不阻断游戏流程
- [ ] **原子写入**：保存时先写临时文件再重命名，避免写入中断导致文件损坏
- [ ] **数据校验**：加载时验证分数为非负整数，非法数据丢弃并使用默认值
- [ ] **路径参数化**：所有函数接收 storage_path 参数，便于测试时传入临时路径
- [ ] **读写测试**：验证保存→加载一致性，异常场景降级逻辑正确

## ?? 验收标准

- [ ] 游戏结束后最高分正确持久化，重启后仍有效
- [ ] 首次运行无配置文件时，load_highscore 返回0不报错
- [ ] 保存失败时有友好提示，游戏流程不受影响
- [ ] 测试时可传入临时路径，不污染用户真实数据
- [ ] 文件格式标准JSON，便于手动查看/编辑
