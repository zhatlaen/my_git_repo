# 模块任务：food（食物管理）

> 文件：src/game/food.py  
> 职责：食物生成、位置管理、绘制

## ? 最小可执行任务清单

- [ ] **初始化**：实现 __init__，接收 Board 和 AssetManager 用于坐标转换和资源加载
- [ ] **食物重生**：实现 espawn(snake_segments)，在空白网格随机生成食物坐标，避让蛇身
- [ ] **获取位置**：实现 get_position()，返回食物当前像素坐标
- [ ] **绘制食物**：实现 draw(surface)，使用像素精灵绘制食物到指定表面
- [ ] **避让逻辑验证**：确保 espawn 不会在蛇身位置生成食物
- [ ] **单元测试**：传入模拟蛇身列表，验证食物生成位置的有效性

## ?? 验收标准

- [ ] 食物始终生成在游戏区域内且不与蛇身重叠
- [ ] espawn 调用后能立即获取到新坐标
- [ ] 绘制函数不依赖全局状态，可独立测试
- [ ] 资源加载失败时有降级方案（如绘制纯色方块）
