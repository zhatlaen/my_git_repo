# 模块任务：pixel_font（像素字体渲染）

> 文件：src/utils/pixel_font.py  
> 职责：像素风格字体渲染辅助

## ? 最小可执行任务清单

- [ ] **初始化**：实现 __init__(font_path, default_size)，加载字体文件，设置默认字号
- [ ] **文本渲染**：实现 ender(text, size=None, color=(255,255,255))，返回 pygame.Surface
- [ ] **字号支持**：支持 8px/12px/16px 三档字号，size 为 None 时使用默认值
- [ ] **颜色配置**：支持自定义RGB颜色，默认白色，符合像素风高对比度需求
- [ ] **空文本处理**：输入空字符串时返回空表面，不报错
- [ ] **字体回退**：指定字体加载失败时，使用系统默认像素字体降级
- [ ] **缓存优化**：相同文本+字号+颜色组合缓存渲染结果，避免重复渲染
- [ ] **渲染测试**：验证不同字号/颜色/文本长度的渲染效果符合预期

## ?? 验收标准

- [ ] 渲染文本边缘清晰，无抗锯齿模糊，符合像素风要求
- [ ] 三档字号渲染尺寸准确，行高一致
- [ ] 颜色参数正确应用，支持透明度（如需）
- [ ] 字体加载失败时有降级方案，程序不崩溃
- [ ] 缓存机制有效，重复渲染相同文本性能提升
