# 模块任务：hud（HUD显示）

> 文件：src/ui/hud.py  
> 职责：实时分数/最高分/蛇身长度进度条显示

## ? 最小可执行任务清单

- [ ] **初始化**：实现 __init__，接收字体/配置/边栏区域参数
- [ ] **数据更新**：实现 update(score, high_score, snake_length)，刷新显示数据
- [ ] **分数渲染**：绘制当前分数和最高分，支持破纪录高亮提示
- [ ] **进度条渲染**：根据蛇身长度绘制进度条（每5节一档，上限150%速度）
- [ ] **操作提示**：绘制当前状态的操作提示（如「按P暂停」「方向键控制」）
- [ ] **像素风格**：所有文本使用像素字体，颜色符合设计规范（#4CAF50/#F44336等）
- [ ] **布局适配**：HUD固定在右侧200px边栏，内容垂直排列
- [ ] **绘制函数**：实现 draw(surface)，将完整HUD绘制到指定表面
- [ ] **更新测试**：验证数据更新后渲染内容同步变化

## ?? 验收标准

- [ ] 分数/最高分实时刷新，数值显示正确
- [ ] 进度条长度与蛇身长度成比例，档位划分清晰
- [ ] 破纪录时分数有高亮/闪烁反馈
- [ ] 所有文本使用像素字体，无模糊/错位
- [ ] HUD绘制不依赖游戏主逻辑，可独立调用测试
